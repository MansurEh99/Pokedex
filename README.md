# Pokédex

A command-line Pokédex written in Go using the [PokéAPI](https://pokeapi.co/).

## Features

- Browse Pokémon locations
- Explore locations and find Pokémon
- Catch Pokémon
- Inspect caught Pokémon
- View your Pokédex
- Navigate through API results
- In-memory API caching

## Requirements

- Go 1.20+
